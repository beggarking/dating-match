# Match Lab — 임베딩 기반 소개팅 추천

내 정보를 입력하면 프로필 저장소(가상 프로필 20명 + 친구)와 한 명씩 비교해서
**누구를 걸렀는지, 무엇에 몇 점을 줬는지, 왜 1위인지** 보여준다.

`index.html` 파일 하나로 동작한다. 서버나 설치 없이 브라우저로 열면 된다.

## 흐름
1. **내 정보 등록** — 직접 입력해 등록(수정·삭제 가능, 이 브라우저에 저장). 성별·나이·지역·흡연·음주, 관심사, 가치관 5문항, 원하는 상대 조건
2. **걸러내기** — 본인, 서로 원하는 성별·나이가 맞지 않는 사람은 점수 계산 전에 제외 (사유 표시)
3. **점수 계산 (100점)**

| 항목 | 배점 | 방법 |
|---|---|---|
| 관심사 | 40 | 관심사를 6가지 성향 축(문화·예술, 액티브, 사교, 집콕, 커리어, 다정) 벡터로 **임베딩**하고 코사인 유사도 계산 |
| 가치관 | 40 | 연애 속도·연락 빈도·주말·성격·만남 목적 (1~5) 답의 차이가 작을수록 높음 |
| 생활 조건 | 20 | 나이차 · 지역 · 흡연 · 음주 |

4. **1위 설명** — 같은 관심사, 성향이 비슷한 관심사(예: 등산~캠핑), 똑같이 답한 가치관, 2위와의 점수 차이

## 임베딩
관심사마다 6차원 벡터를 정해 두고(예: 등산 = 액티브 축 1.0), 한 사람의 관심사 벡터를 모두 더해
그 사람의 취향 벡터를 만든다. 두 사람 벡터의 코사인 유사도가 관심사 점수다.
그래서 같은 단어가 하나도 없어도 성향이 비슷하면(등산 ↔ 캠핑) 점수가 높게 나온다.

## 저장
가상 프로필은 `index.html` 안에 들어 있고, 친구 프로필과 내 정보는 브라우저(localStorage)에만 저장된다.
