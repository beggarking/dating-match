# 교만추 — 교통대 학생을 위한 임베딩 기반 소개팅 추천

한국교통대 학생들이 쓰는 소개팅 추천 앱. 내 프로필을 프로필 저장소
(가상 프로필 20명 + 내 정보를 입력한 학생들)와 한 명씩 비교해서
**누구를 걸렀는지, 무엇에 몇 점을 줬는지, 왜 1위인지** 점수순으로 보여준다.

## 흐름
1. **회원가입** — 학번(7자리) · 이름 · 닉네임 · 비밀번호만 입력. 닉네임은 [중복확인]을 통과해야 가입된다
2. **내 프로필** — 왼쪽 위 동그란 사진을 누르면 열린다. 사진 · 이름, 나이 · 한 줄 소개 · 내 평점(5점 만점) ·
   추천 후보들과의 항목별 평균 궁합(관심사 · 가치관 · 나이 · 지역 · 흡연 · 음주 %). 연필 버튼 / [내 정보 수정]으로 수정 화면에 들어간다
3. **내 정보 수정** — 프로필 사진 · 닉네임(변경 시 중복확인) · 학과 · 성별 · 나이 · 거주 지역 · 흡연 · 음주 · 한 줄 소개 · 관심사 · 가치관 5문항 · 원하는 상대 성별
4. **점수 매칭** — 내 프로필을 저장소의 모든 사람과 1:1 비교
   - **걸러내기**: 본인, 서로 원하는 성별이 맞지 않는 사람은 점수 계산 전에 제외 (사유 표시). 나이는 다 같은 학교 학생이라 거르지 않는다
   - **점수 계산 (100점)**

| 항목 | 배점 | 방법 |
|---|---|---|
| 관심사 | 40 | 관심사를 6가지 성향 축(문화·예술, 액티브, 사교, 집콕, 커리어, 다정) 벡터로 **임베딩**하고 코사인 유사도 계산 |
| 가치관 | 40 | 연애 속도·연락 빈도·주말·성격·만남 목적 (1~5) 답의 차이가 작을수록 높음 |
| 생활 조건 | 20 | 나이차 · 지역 · 흡연 · 음주 |

   - **1위 설명**: 같은 관심사, 성향이 비슷한 관심사(예: 등산~캠핑), 똑같이 답한 가치관, 2위와의 점수 차이
5. **커뮤니티 (홈)** — 글이 말풍선으로 올라오고, 글을 누르면 댓글을 달 수 있다. 글쓴이 사진을 누르면 프로필 창(나와의 항목별 궁합)에서 대화 요청
6. **오늘의 추천** — 하루 5번(한국 시간 기준, 서버에서 횟수 확인), 서로 원하는 성별이 맞는 사람 중 랜덤으로 한 명씩.
   패스 / 대화 요청 / 별점(1~5) 주기
7. **인기 랭킹** — 오늘의 추천에서 받은 별점 평균 순 TOP 10
8. **대화** — 탭 줄 오른쪽 끝의 대화 상자. 받은 대화 요청을 상대 프로필을 보고 수락하면 채팅이 열린다
   (안 읽은 메시지 · 받은 요청 수를 빨간 숫자로 표시, 열린 채팅은 4초마다 새 메시지 확인). 서로 요청하면 바로 연결
- 화면 위쪽에 회원 수(내 정보를 입력한 회원)와 프로필 저장소 인원을 숫자로 보여준다

## 로직을 눈으로 보기
- **취향 레이더 차트** — 1위 카드에 나와 상대의 6가지 성향(임베딩)을 겹쳐 그린다. 두 모양이 많이 겹칠수록 관심사 점수가 높다.
- **내 기준 조정** — 관심사·가치관·생활 조건의 비중을 슬라이더로 바꾸면 순위가 바로 다시 계산된다.
  점수표에 기본 기준(40·40·20) 대비 순위 변화(▲▼)가 표시되고, 1위가 바뀌면 기본 기준의 1위도 알려준다.

## AI 설명 (로컬 LLM)
1위 카드의 [AI에게 1위 이유 듣기] 버튼. 점수 · 순위는 바꾸지 않고, 점수 로직의 결과를 근거 문장으로 만들어
**방문자 브라우저 안에서 도는 LLM**(transformers.js + Qwen3.5 0.8B)이 왜 1위인지 문장으로 설명한다.
- 문장 임베딩 모델(multilingual-e5-small)로 나와 상위 후보 5명의 "한 줄 소개 + 관심사" 의미 유사도를 계산해 근거에 넣는다
- LLM 문장에 근거에 없는 숫자 · 1위 이름 누락 · 외국 문자가 있으면 다시 쓰고, 그래도 틀리면 근거 문장을 그대로 보여준다
- 서버 · 외부 API 없음. 처음 누를 때만 모델(약 600MB)을 받고 이후에는 브라우저에 저장된 모델을 쓴다

## 임베딩
관심사마다 6차원 벡터를 정해 두고(예: 등산 = 액티브 축 1.0), 한 사람의 관심사 벡터를 모두 더해
그 사람의 취향 벡터를 만든다. 두 사람 벡터의 코사인 유사도가 관심사 점수다.
그래서 같은 단어가 하나도 없어도 성향이 비슷하면(등산 ↔ 캠핑) 점수가 높게 나온다.

## 구성 · 저장
- `index.html` — 화면과 추천 로직 전부 (빌드 없음, GitHub Pages로 배포)
- `supabase-setup.sql` — 회원 · 프로필 DB. Supabase 대시보드 > SQL Editor 에 붙여넣고 Run (여러 번 실행해도 안전)
  - 브라우저는 테이블에 직접 접근할 수 없고 `ml_*` 함수(가입 · 로그인 · 내 정보 수정 · 후보 목록 · 오늘의 추천 · 별점 · 대화 요청 · 커뮤니티 · 탈퇴)만 호출한다
  - 비밀번호는 bcrypt 해시로만 저장, 로그인하면 30일짜리 세션 토큰 발급
  - 다른 학생에게는 학번 · 실명을 공개하지 않고 **닉네임**과 매칭용 프로필만 보여준다
  - 프로필 사진은 브라우저에서 240px JPEG로 줄여 프로필과 함께 저장
  - 별점 · 대화 요청은 오늘의 추천 기록이 있어야 가능(대화 요청은 커뮤니티 글쓴이에게도 가능)
  - 닉네임은 한글 · 영문 · 숫자 · _ 2~12자, 대소문자 구분 없이 중복 불가 (DB 고유 인덱스)
- 가상 프로필은 `index.html` 안에 있고, 회원이 내 정보를 저장하면 DB에 들어가 다른 학생들의 추천 후보(저장소)에 자동으로 포함된다.
- 인기 랭킹 시연을 위해 가상 프로필에는 랜덤으로 정한 기본 별점이 있고, 실제로 받은 별점과 합쳐서 보여준다.
