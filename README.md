# Match Lab — 임베딩 기반 소개팅 추천

내 프로필을 올리면 프로필 저장소(가상 프로필 + 친구)와 1:1로 비교해서,
**추천 상대와 그 상대를 고른 근거**를 점수 순으로 보여준다.

## 실행
```
python -m venv .venv
.venv\Scripts\pip install fastapi "uvicorn[standard]" fastembed numpy
.venv\Scripts\python -m uvicorn app:app --port 8000
```
http://127.0.0.1:8000 접속 → ① 내 프로필 저장 → (② 친구 추가) → 추천 받기
(첫 실행 때 임베딩 모델 약 1.2GB를 내려받는다)

## 추천 로직 (`matcher.py`)
1. **필수 조건**: 서로의 선호 성별·나이 범위가 안 맞으면 제외 (사유 표시)
2. **임베딩**: `google/embeddinggemma-300m` 으로 자기소개·가치관·이상형·관심사를 벡터화
3. **항목 점수** (코사인 유사도를 0~1로 보정)

| 항목 | 가중치 | 방법 |
|---|---|---|
| 이상형 상호적합 | 30% | 내 이상형↔상대 소개, 상대 이상형↔내 소개의 조화평균 |
| 가치관 유사도 | 25% | 가치관 글 임베딩 유사도 |
| 관심사 매칭 | 20% | 관심사 단어별 임베딩 → 의미가 가까운 쌍 찾기 (등산↔트레킹) |
| 자기소개 결 | 10% | 자기소개 글 임베딩 유사도 |
| 생활 조건 | 15% | 나이차·지역·흡연·음주 (규칙) |

4. **총점** = Σ 가중치 × 항목점수 × 100 → 내림차순 정렬
5. **설명**: 항목별 막대, 추천 이유/주의점, 의미가 가장 비슷한 문장 쌍을 함께 표시

## 파일
- `app.py` — API 서버 · `matcher.py` — 점수/설명 로직 · `embedder.py` — 임베딩
- `data/profiles.json` — 프로필 저장소 · `static/index.html` — 화면
